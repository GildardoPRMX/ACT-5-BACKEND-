# Task API con Express y TypeScript (EC2 F2 A6)

API REST para la gestión de tareas con modelo Mongoose 8, persistencia en MongoDB Atlas, diagnóstico de disponibilidad y operaciones asíncronas. Práctica guiada **EC2 F2 A6** para la asignatura *Programación Backend con Frameworks* (Universidad Estatal de Sonora).

Consulte la documentación completa en [README.md](./README.md).
